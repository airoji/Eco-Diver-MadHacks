✨ How the Die-Cut Sticker “Fishies” Were Made

Each sea creature is 100% procedurally drawn in code using the HTML5 <canvas> 2D API (no external image files!) using a multi-pass “vinyl die-cut sticker” pipeline:

1. Bezier Silhouette Path Smooth cubic and quadratic curves (quadraticCurveTo, ellipse, arc) trace the rounded body, tail fin, and spikes of each creature.
2. White Die-Cut Sticker Border (Pass 1) Before filling any color, the path is stroked with a thick, pure-white line (lineWidth = 9.5, lineJoin = "round"), creating that crisp vinyl-sticker halo around the entire fish.
3. Pastel Fill & Hand-Drawn Ink Outline (Pass 2) The exact same path is filled with warm pastel colors (such as #f472b6 rosy pink, #60a5fa sky blue, or #f59e0b amber gold) and stroked again with a thinner warm dark-brown ink outline (#4a2511, lineWidth = 2.8).
4. Kawaii Details & Scales (Pass 3) Finally, we layer glossy dark eyes with tiny white specular highlight dots, soft translucent pink blush ovals on the cheeks, and tiny white U-shaped scale arcs along their sides.
